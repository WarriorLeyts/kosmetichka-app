# API для мобильного приложения

Новые маршруты `app/api/mobile/*` для репозитория сайта. Это только **новые файлы** — ни один существующий
файл сайта не меняется, страницы и API сайта работают как раньше.

Используют то, что на сайте уже есть: `@/lib/prisma`, `@/lib/auth`, `bcryptjs`, cookie `auth_token`.

Установка: скопировать папку `app/api/mobile` в корень сайта (`app/api/mobile`) и задеплоить.
