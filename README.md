# Косметичка — мобильное приложение (iOS + Android)

Отдельный проект, сделанный из копии сайта [kosmetichka-b2b](https://github.com/WarriorLeyts/kosmetichka-b2b).
Сайт и его репозиторий этот проект **не затрагивает**: изменения здесь никак не попадают на сайт.

## Как устроено

- Интерфейс — те же React-компоненты, что на сайте, собранные в статический бандл (`next build` → `out/`).
- Бандл упакован в нативное приложение через **Capacitor** (одна кодовая база для iPhone и Android).
- Данные приложение берёт с того же сервера, что и сайт: `https://kosmetichka-opt.ru/api/...`
  (адрес задаётся переменной `NEXT_PUBLIC_API_BASE`, см. `lib/api.ts`).
- Сетевые запросы идут через нативный HTTP (CapacitorHttp): вход по cookie работает, CORS на сервере настраивать не нужно.

## Что работает сразу (на существующем API сайта)

Главная, каталог с поиском и фильтрами по категориям, карточка товара, корзина и оформление заказа,
вход/регистрация/восстановление пароля, избранное, сравнение, лист ожидания, уведомления о заказах, чат по заказу.

## Что заработает после добавления API на сервер

Папка `server-addon/` — **новые** файлы для сайта (`app/api/mobile/*`). Существующий код сайта они не меняют.
Пока их нет на сервере, приложение показывает в этих разделах кнопку «Открыть на сайте».

| Эндпоинт | Зачем |
|---|---|
| `GET /api/mobile/orders` | экран «Мои заказы» |
| `GET /api/mobile/orders/:id` | детали заказа |
| `GET/PATCH /api/mobile/profile` | экран профиля и сохранение |
| `GET /api/mobile/catalog-meta` | фильтр по брендам в каталоге |
| `GET /api/mobile/home` | счётчики на главной |

Чтобы подключить: скопировать содержимое `server-addon/app/api/mobile` в `app/api/mobile` репозитория сайта и задеплоить.

## Сборка

Собирается автоматически в GitHub Actions при каждом пуше в `main`:

- **Android** (`.github/workflows/android.yml`) — APK лежит в разделе Actions → последний запуск → Artifacts.
  Устанавливается на телефон напрямую (разрешить установку из неизвестных источников).
- **iOS** (`.github/workflows/ios.yml`) — без аккаунта Apple проверяет, что приложение собирается.
  После добавления секретов Apple (список в начале файла) сам подписывает и отправляет сборку в **TestFlight**.

Локально (нужен Node 20+):

```bash
npm install
npm run dev                         # открыть в браузере http://localhost:3000
scripts/prepare-native.sh android   # сгенерировать Android-проект (нужен Android Studio)
```
